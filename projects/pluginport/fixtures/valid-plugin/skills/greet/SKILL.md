# Greet skill

Use this skill when the agent needs to open a reply with an appropriate greeting.

## When to use

- User-facing chat responses
- Onboarding or welcome flows
- Situations where tone (formal vs casual) must match the user

## Instructions

1. Match the user's language and formality.
2. Keep greetings to one short sentence unless the user asked for more.
3. Avoid generic filler like "Hello there!" without context.
